# 地级市人口老龄化工具变量（MATLAB）

依据用户提供的《IV构建.docx》和“梳理参数估计思路”对话，实现以 **2000 年城市年龄结构**预测 2010、2020 年老龄化，并构造 **2010—2020 年长差分**。原始数据仅在本地读取，不随代码上传；本仓库不包含真实城市估计结果。

## 已适配的原始工作簿

`run_iv_workbook.m` 直接读取同一目录中的 `iv-essential data2.xlsx` 和 `total.xlsx`（均为 Sheet1），无需手工转表。原来的 `iv-essential data.xlsx` 仍保留女性人口表头，因此入口明确选择已更正表头的 data2 版本。若后续重命名文件，请修改入口顶部路径。

城市读取器排除末尾三行明确标为“合计”的记录，保留 287 市 × 3 年共 861 行；不随意删除无城市编码的记录。合并 0 岁及 1—4 岁为 0—4 岁，最终组为 85+，并保留城市名称。平均年龄、劳动平均年龄不参与 IV。全国读取器读取 `A1:D22`，忽略平均年龄空行和数万行空白格式。

2026-09-28 对更新文件的核对发现：

1. `iv-essential data2.xlsx!O48`：保山市2010年40—44岁人口为 **11,884,853,853**。该值也进入 `total.xlsx!C13`，使该年龄组参考人口达到 **12,000,603,484**。应核实原始统计来源并同时更新城市及参考表，程序不会猜测或自动截断正确值。
2. total 的三期全部19个原始年龄分组均精确等于287市加总；合并0—4岁后54个年龄—年份单元仍全部相等。不能仅因文件名为 total 就认定它是独立全国数据。默认 `referenceScope="national"` 遇到这种情况会停止。若明确选择样本合计的替代设计，可设为 `"sample_aggregate"`，输出将保留该标签。这个替代设计不是文档的全国共同变化率方案，而且参考变化率包含各研究城市自身的后期人口；它不自动解决迁移内生性或满足排除性约束。

入口先保存城市异常、参考人口异常、参考覆盖比较三份诊断，再检查是否可以计算。单个城市年龄组超过该市总人口50%、参考年龄组超过总数25%、参考人口总数相对2000年超过2倍或低于0.5倍，均要求核实。这些是数据审查阈值，不是存活率限制；不会将g限制为0—1。仅在原始来源确实支持异常数值时才允许显式开启对应 `allowReviewed...` 参数。

修正数据并确定参考口径后运行 `run_iv_workbook`。每次运行在 `results/` 新建独立子目录，失败只留下诊断，不复用旧IV结果。成功后保存标准化输入、城市IV、队列核对表及MAT文件。`run_iv` 供已核实的通用长表使用，不包含工作簿入口的额外异常审查。

验证记录：独立读取已核对287市三期覆盖、人口字段非负且无缺失、城市年份唯一，并确认上述异常和样本加总关系。本机 MATLAB 仍在启动时报 `File system inconsistency`，尚未成功执行 MATLAB 测试。`test_build_aging_iv.m` 覆盖解析结果、尾组、g>1、乱序、重复、缺失、预测不依赖本市后期人口，以及城市/参考异常和样本加总识别。提供测试不等于 MATLAB 测试通过；当前未生成可用的真实IV结果。

## 运行

使用 MATLAB R2020b 或更新版本，无须额外工具箱。将代码放在同一目录，准备下述两个输入文件，然后运行：

```matlab
test_build_aging_iv  % 合成数据验证
run_iv_workbook     % 直接读取两个已适配的Excel，先输出诊断
% run_iv            % 已整理且核实的通用长表输入
```

也可直接传入 MATLAB table：

```matlab
[iv, cohortAudit] = build_aging_iv(city, national);
```

`run_iv.m` 顶部可修改路径。可将 CSV 路径换为具有相同表头的 XLSX；多工作表文件需自行在 readtable 中指定 Sheet。现有宽表应先整理成长表，不能只改列名而保留宽表布局。

## 输入格式

`data/city_age.csv`：每行一个城市、年份、五岁年龄组。

| city_id | year | age_start | population |
|---|---|---|---|
| 110100 | 2000 | 0 | 该组人口数 |
| 110100 | 2000 | 5 | 该组人口数 |
| … | … | … | … |
| 110100 | 2000 | 80 | 80岁及以上人口数 |

`data/national_age.csv`：列为 `year,age_start,population`，存放全国三个普查年份的同口径人口数。表内不要混入城市行、男女分项、总计行。城市表同理，每组只保留一个合计人口数。

- 年份必须为 2000、2010、2020；城市 ID 按文本读取。
- 每个城市每年必须完整且唯一地包含 `0,5,10,...,T`；全国使用同一组界。最后一组表示 `T+`，不是 `T` 至 `T+4`。要求 T≥80。
- 输入为人数或统一单位的人口数量，不能用各年年龄占比代替全国人数。城市各年数量单位保持一致；全国各年必须同一单位。
- 不自动填零、插值、拆分粗年龄组或删除缺失城市；重复、缺组、负数、缺失会报错。
- 请先统一城市行政区划和人口统计口径（常住/户籍、全市/市辖区）。程序只能检查表结构，不能自动验证这些实质条件。
- 全国人数需要单独准备。有限研究城市的加总不自动等于全国；程序不默认以样本城市加总替代全国人口。

## 公式与输出

对普通五岁年龄组，`g(b,tau)=P_N(b+tau,2000+tau)/P_N(b,2000)`，`P_hat=P_city(b,2000)*g`。tau 分别为 10、20，两个预测均直接使用 2000 年基期，不使用 2010 年城市人口作为 2020 年预测起点。

`OR = P(60+)/P(20+)`。输出 `iv_2010_2020.csv` 每市一行：

- `OR_2010, OR_2020`：实际比率；`pred_OR_2010, pred_OR_2020`：预测比率。
- `D = log(OR_2020)-log(OR_2010)`：被工具化的实际变化。
- `Z = log(pred_OR_2020)-log(pred_OR_2010)`：工具变量。
- 同时保留实际及预测的 60+、20+人数。

`cohort_audit.csv` 保留城市、目标年份、基期/目标年龄组、开放组标记、全国分子分母、g 和预测人数，用于复核。g 可能超过 1，不截断；它是人口队列变化率，不是严格的纯死亡存活概率。

## 最高开放年龄组

文档要求一致处理开放组，但未给出具体算法。这里采用**按预测跨度合并基期尾部**的约定：目标 T+ 对应基期 (T−tau)+，用 `全国目标T+ / 全国基期(T−tau)+` 乘以城市基期 (T−tau)+。每次预测只计算一次这个尾组。

例如 T=80：2010 年的 80+ 由 2000 年 70+ 预测；2020 年的 80+ 由 2000 年 60+ 预测。不会把同一个 80+ 总人数反复匹配到多个基期组。T≥80 保证两种跨度的尾部合并不跨越目标 20+、60+ 门槛。

这是可复现的尾部聚合近似：合并后隐含城市尾组内部年龄构成与全国足够可比。若有更细的高龄组，优先统一到更高的开放门槛，并对尾部口径做敏感性检验。

## 与 TFP 回归衔接

在完成城市 ID 匹配后，另行构造 `Y=log(TFP_2020)-log(TFP_2010)`；只有 TFP 为正的水平指标才使用该公式。若已有 log(TFP)，直接相减，不能再取一次对数。TFP 缺失值需明确记录，不能视为零。

第一阶段 `D = constant + pi*Z + X*gamma + u`；第二阶段以 Z 工具化 D，解释 Y。控制变量采用研究设计确定的事前城市特征。本程序负责人口数据处理，不自动选择控制变量或执行 2SLS，也不报告未经实际样本检验的第一阶段强度。

OR 不是“60+/总人口”，不能在未改变识别设计的情况下混用。单个长差分截面每市一行，不添加城市固定效应，也不把 Z 复制到 2004—2022 年面板。应在实际回归时报告合适的标准误、第一阶段与弱工具变量检验；历史年龄结构并不天然满足排除性约束。

本实现依据所提供文档，不声称复现参考论文的全部实证设定。真实数据尚未接入时，合成测试通过也不代表数据口径或 IV 有效性已得到验证。
