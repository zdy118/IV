# IV 构建：Stata

本目录仅保留 [national_g.do](national_g.do) 和 [run_iv.do](run_iv.do)。两份代码来自原 `stata-iv` 最新版本，本次只移动文件，未修改计算或输入处理。

## 输入与执行顺序

在 Stata 中手动导入 Excel，完整运行 do-file，避免临时文件宏跨执行作用域失效。生成的同名结果会被覆盖。

1. 全国人口：使用 `total_national.xlsx`。导入后的 A、B、C、D 分别为年龄标签与2000、2010、2020年人口；执行 `national_g.do`，生成 `national_g.dta/.xlsx`。
2. 城市人口：使用现有城市年龄人口表。当前代码要求内存中已经具有 `city_id city_name year`，以及按原顺序排列、数值型的 F—X 年龄人口列。需要在运行前自行处理名称、编码、年份、合计行和数值类型。执行 `run_iv.do`，生成 `iv.dta/.xlsx`。

城市年龄列 F—X 依次为0岁、1—4岁、5—9岁，直至80—84岁、85+。每市须有2000、2010、2020三期。

代码与数据可放在不同目录。当前 `run_iv.do` 内合并全国 g 的路径固定为 `D:\SZU\aging&TFP&labour\aging\IV\national_g.dta`；请将全国输出放在那里。结果输出位置是 Stata 当前工作目录。

## 当前版本的已知输入差异

`national_g.do` 的导入注释为 A4:D22（19行），但实际检查为 `assert _N==20`；尾组又使用合并后的第18行。该差异已存在于本次整理前的最新代码，需要核对实际年龄组后再运行，不能简单增加空行或合计行来满足断言。按本次“代码内容不调整”的要求原样保留。

`run_iv.do` 顶部仍保留 A—X 与自动删除合计行的旧注释，但当前正文已不包含相应预处理；请以上述实际输入要求为准。本次没有重跑脚本，也不将旧版本的运行记录视为当前版本通过验证。

## 计算口径与输出

两期预测均以2000年为基期。普通组 g 为目标年对应队列人口除以2000年人口，不减1、不年化、不截断至1。2010年85+对应2000年75+，2020年85+对应2000年65+；开放尾组先合并再推进。

- `national_g.dta/.xlsx`：`age g10 g20`；age 为2000年基期年龄下限。
- `iv_2010_2020.dta/.xlsx`：每市一行，包含 `city_id city_name OR2010 OR2020 predOR2010 predOR2020 D Z`。
- `OR=60岁及以上人口/20岁及以上人口`。
- `D=ln(OR2020)-ln(OR2010)`。
- `Z=ln(predOR2020)-ln(predOR2010)`。

全国数据应使用全国普查口径，不能用样本城市汇总替代。后续见 [内生性检验](../endogeneity/README.md)。
