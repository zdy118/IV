# Stata：手动导入 Excel 后构建 IV

只需两个 do 文件，无须配置路径宏、加载程序库或运行导入器。Stata 16及以上可用。

## 操作顺序

先在 Stata 中选定一个工作目录，两步均使用同一目录；生成的同名结果文件会覆盖旧结果。脚本直接处理当前内存数据，运行前请保存其他数据。

1. 手动导入 `total_national.xlsx` 的 Sheet1，单元格范围 **A4:D22**，**不勾选“首行作为变量名”**。确认变量为 A、B、C、D，分别对应年龄标签和2000、2010、2020年全国人口。运行 [national_g.do](national_g.do) 全文。
2. 手动导入 `iv-essential data2.xlsx` 的 Sheet1，单元格范围 **A2:X865**，同样**不勾选“首行作为变量名”**。确认变量为 A—X，保持原始列顺序。运行 [run_iv.do](run_iv.do) 全文。

两个文件都不自动导入 Excel，也不清空刚导入的数据。若城市表以后增加行数，手动调整导入范围的末行。全国表必须保持原有19行年龄组顺序；不要排序后再运行脚本。请使用全国普查表，不能用样本城市汇总的 `total.xlsx`。

城市列顺序为：名称、编码、年份、平均年龄、劳动平均年龄、0岁、1—4岁、5—9岁……80—84岁、85+。代码忽略两个平均年龄列，自动去掉“合计”行、合并0岁与1—4岁。仅保留必要的缺失、非负值、城市年份唯一性和三期完整性检查。

## 输出与计算

- `national_g.dta / national_g.xlsx`：age为2000年基期年龄，g10、g20分别是向2010、2020年推进的全国人口比。宽表16行，共30个有效g；age为70、75时g20为空，属正常情况。
- `iv_2010_2020.dta / iv_2010_2020.xlsx`：每市一行，含实际OR、预测predOR、D、Z，可按city_id合并回归数据。

两期预测均以2000年为基期。普通组的g是目标年相应队列人口除以2000年人口，不减1、不年化、不截断至1。2010年85+对应2000年75+；2020年85+对应2000年65+。全国分母和城市基期人口均先合并相应尾部，再预测一次，避免重复计数。开放尾组依赖内部年龄构成可比的近似假设。

`OR=60岁及以上人口/20岁及以上人口`。
`D=ln(OR2020)-ln(OR2010)`。
`Z=ln(predOR2020)-ln(predOR2010)`。

2026-10-03已使用现有Excel在Stata/MP 18实际运行：输出287市；六项OR、predOR、D、Z与已独立复核的原版结果相比，最大差异为7.8e-16。此验证针对计算实现，不包含IV识别假设检验。
